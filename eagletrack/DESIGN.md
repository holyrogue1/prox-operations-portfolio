# EagleTrack Public Showcase

Scope: independently authored static demo and case page. No company source,
records, configuration, workbook or real-data screenshots may be copied here.
Native C# WPF screenshots must use synthetic data and neutral labels, with no
company identifiers, and be labelled separately from the browser prototype.

Preserve the parent portfolio. Link to a dedicated EagleTrack case page and
direct-entry demo. Existing portfolio tokens govern the introduction; the
demo is a compact, light operational workbench. All demo data is fabricated.

## Visual Contract
- Canvas #f3f6f5; paper #ffffff; ink #202d2c; muted #576b68.
- Line #d7e1de; accent #176d61; soft #e7f2ee.
- BOM blue #1667b0; production red #ba3535; caution #8a5b12.
- Body: Segoe UI, Malgun Gothic, sans-serif, 14px; headings 22/28px.
- Fixed font sizes, zero tracking, 4px radii, 4/8/12/16/24/32px spacing.
- Touch controls >=44px, focus outline, native forms/dialogs, visible labels.
- Stable chart heights and responsive grid; tables scroll within their region.
- Series always have text labels; no state conveyed by color alone.
- Actual screenshots of the synthetic demo are the showcase visual assets.

## Behavior Contract
- Direct entry only; no workbook upload or production connections.
- Each demo project has one product, explicit installation type and unit.
- Stage records are cumulative totals, not additive transactions. History
  retains previous and new values. Null means missing, never zero.
- BOM expected = product production-instruction quantity * component usage per product unit.
- Production valuation = entered material quantity * the SAME BOM unit price.
- Require the same explicit component unit; no guessed conversions.
- Dashboard counts are calculated from the synthetic state, not performance claims.
- C# product architecture and integration roadmap are distinct from the web demo.
- PLM/PDM/PMS/SCM/MES are integration domains, not completed module claims.
